# تحدّي الأمن السيبراني

موقع عربي تفاعلي جاهز للنشر، لا يحتاج إلى حسابات أو قاعدة بيانات أو خادم.

## التشغيل على جهازك
1. فك ضغط الملف.
2. افتح `index.html` في Chrome أو Edge أو Firefox.
3. اضغط «ابدئي التحدّي».

## النشر على الإنترنت
**GitHub Pages**
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع ملف `index.html` إلى المستودع.
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch ثم الفرع `main` والمجلد `/root` ثم Save.
5. انتظر رابط الموقع الذي سيظهر في صفحة Pages.

**Netlify**
1. افتح https://app.netlify.com/drop
2. اسحب مجلد المشروع بعد فك الضغط إلى الصفحة.
3. سيظهر رابط الموقع مباشرة.

## تعديل بنك الأسئلة
الأسئلة موجودة في بداية كود JavaScript داخل المتغير `BANK`.
كل سؤال مرتب بهذا الشكل:
`[نص السؤال, [أربعة اختيارات], رقم الإجابة الصحيحة من 0 إلى 3, ملاحظة داخلية غير مستخدمة, التصنيف, تفسير الإجابة]`

## الخصوصية
لا توجد حسابات أو نماذج أسماء أو إرسال بيانات إلى أي خادم. يتم احتساب النتيجة داخل المتصفح فقط ولا يتم تخزينها بعد إغلاق الصفحة.
